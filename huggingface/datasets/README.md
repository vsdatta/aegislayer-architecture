# Hugging Face Dataset Packages

This directory contains public, synthetic, deterministic datasets prepared for Hugging Face Dataset repositories.

## Dataset Packages

- `aegislayer-governance-scenarios`
- `threat-control-map`
- `architecture-catalog`

## Guardrails

- No personal data
- No production telemetry
- No benchmark claims
- No training-set claims
- No evaluation-set claims
- No secrets

Each dataset package includes a dataset card, schema, limitations, license note, and machine-readable sample files.
