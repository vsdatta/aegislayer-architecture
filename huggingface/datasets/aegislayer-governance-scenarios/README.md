# AegisLayer Governance Scenarios

## Summary

Synthetic deterministic scenarios showing how a governed AI action system may produce allow, deny, conditional approval, revocation, escalation, or containment outcomes.

## Scope

- conceptual and educational
- non-personal
- non-production
- static and deterministic

## Included Scenarios

- low-risk allow
- unauthorized deny
- high-impact approval required
- connector unavailable
- capability expired
- capability revoked
- evidence incomplete
- containment triggered
