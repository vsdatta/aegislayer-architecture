# AegisLayer Threat Control Map

## Summary

Synthetic threat-to-control mappings linking public threat families to architecture principles, related ADRs, documentation links, and residual risk statements.

## Fields

- threat identifier
- threat family
- affected asset
- control principle
- related ADR
- documentation link
- residual risk statement

## Files

- `data/threat_control_map.csv`
- `data/threat_control_map.jsonl`
- `schema.json`
- `LIMITATIONS.md`
- `LICENSE.md`

## Scope Boundary

This is a public reference mapping. It is not a full enterprise threat model and should not be represented as environment-specific risk analysis.
