# Tagging Strategy

## Approved Tags by Theme

- Governance-focused Spaces: `ai-governance`, `governance`, `responsible-ai`, `human-in-the-loop`, `explainability`
- Security-focused Spaces: `ai-security`, `zero-trust`, `runtime-security`, `cybersecurity`, `llm-security`
- Agent-runtime Spaces: `agentic-ai`, `autonomous-agents`, `runtime-security`, `auditability`
- Evidence and library assets: `auditability`, `trustworthy-ai`, `explainability`, `governance`

## Rules

- Use only tags that describe the published artifact directly.
- Do not use unrelated trending tags.
- Do not imply a model, benchmark, evaluation suite, or production service when the artifact is documentation or a static explainer.
- Keep tag lists short enough to remain truthful and specific.

## Default Baseline

For most core AegisLayer Spaces, start with 4 to 6 tags chosen from the approved list in `SPACE_METADATA_GUIDE.md`.
