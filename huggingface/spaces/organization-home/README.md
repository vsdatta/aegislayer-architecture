## What AegisLayer Publishes

AegisLayer publishes architecture guidance, governance principles, trust-boundary diagrams, conceptual SDK examples, synthetic datasets, and research planning artifacts for governed AI action systems.

- Canonical GitHub repository and Pages docs
- Public Hugging Face static Spaces
- Synthetic datasets with schema and limitations
- Reference SDK examples and tests
