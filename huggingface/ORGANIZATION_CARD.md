# AegisLayer Organization Card

AegisLayer is a public reference-architecture and research initiative for governed AI-initiated action systems. It focuses on how autonomous and agentic AI capabilities can be constrained by explicit authority boundaries, policy-before-execution controls, accountable approvals, scoped connectors, evidence generation, and fail-closed runtime verification.

## Who Develops It

AegisLayer is developed and maintained by VND TECH LLC as a public, reproducible architecture program published from the canonical GitHub repository.

## Public Reference-Architecture Scope

AegisLayer publishes only public reference materials:

- architecture and governance documentation
- trust-boundary and lifecycle diagrams
- a conceptual reference SDK
- deterministic static Spaces for public exploration
- synthetic Hugging Face datasets for educational use
- public research planning artifacts

It does not publish private production internals, customer deployments, or secret-dependent runtime systems.

## Seven Core Governance Principles

1. Separate AI reasoning from execution authority.
2. Validate identity and authority before authorization.
3. Evaluate policy before execution.
4. Require accountable approval for high-impact actions.
5. Scope connector access through explicit capabilities.
6. Generate evidence by design.
7. Continuously verify runtime trust and fail closed on drift.

## Research and Learning Focus

AegisLayer concentrates on AI governance, AI security, zero-trust execution design, evidence and auditability, human approval flows, threat-to-control traceability, and runtime containment and recovery for agentic systems.

## Public Limitations and Disclaimers

- AegisLayer materials are conceptual and educational.
- The repository does not claim production certification, endorsements, or universal attack prevention.
- Static Spaces do not execute external actions or provide live policy enforcement.
- Synthetic datasets are deterministic reference data, not empirical benchmarks, production telemetry, or training corpora.
