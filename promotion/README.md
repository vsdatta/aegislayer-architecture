# Promotion Program

This directory contains the public, non-spam launch and update system for AegisLayer Hugging Face publication.

## Principles

- link to useful artifacts
- disclose conceptual or reference status
- invite specific feedback
- avoid hype and unverifiable claims
- avoid repetitive posting

## Included Assets

- 90-day content calendar
- post templates
- discussion starters
- announcement copy
- metrics framework
- ethical promotion policy
