# Metrics Framework

## Ethical Success Metrics

- Space visits
- likes
- followers
- repository stars
- documentation visits
- meaningful discussion replies
- SDK usage signals
- dataset downloads
- returning visitors
- contributor activity

## Rules

- record observed values only
- never estimate or fabricate current metrics
- separate vanity metrics from meaningful engagement
- pair numeric trends with qualitative notes

## Manual Tracking Schema

```csv
date,channel,artifact,metric_name,metric_value,source,notes
2026-08-02,hugging-face,organization-home,space_visits,0,manual-baseline,Fill with observed value only
```

## Interpretation Notes

- A visit count alone is not proof of understanding.
- Replies that identify ambiguity or ask specific technical questions are higher-signal than raw reactions.
- Returning visitors and contributor activity are stronger indicators of durable interest than one-time spikes.
