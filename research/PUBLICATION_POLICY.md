# Publication Policy

## Canonical Source

GitHub repository content is canonical for architecture and technical references.

## Public Release Conditions

Before publication:

- Verify references and cross-links.
- Confirm scope boundaries and non-sensitive content.
- Use clear labels for conceptual and planned material.
- Ensure owner review for externally visible claims.

## External Publication Destinations

- GitHub Pages: official technical documentation.
- Hugging Face: research discovery and static demonstrations mirroring canonical outputs.

External mirrors must not become independently edited sources of truth.
