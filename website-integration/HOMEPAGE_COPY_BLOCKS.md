# Homepage Copy Blocks

## Architecture Summary Block

AegisLayer is a public reference architecture for governing AI-initiated actions through identity-first authorization, policy-before-execution controls, risk-based approvals, capability-scoped connector trust, and evidence-driven runtime containment.

## Security Disclaimer Block

AegisLayer materials are conceptual and educational. They are designed to improve risk reduction and accountability, not to claim universal prevention of all security incidents.

## Platform Roles Block

- GitHub: canonical architecture and source
- GitHub Pages: official technical docs
- Hugging Face: research discovery and static demonstrations
- aegislayer.ai: organization and product-facing presence
