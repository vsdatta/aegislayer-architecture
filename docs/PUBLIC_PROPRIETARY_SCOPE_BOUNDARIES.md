# Public vs Proprietary Scope Boundaries

## Public Repository Scope

- Reference architecture and governance model
- Threat model and control traceability
- ADR/RFC decision framework
- Conceptual SDK and static demo artifacts
- Public research outlines

## Proprietary Scope (Not Published Here)

- Production implementation internals
- Customer-specific control mappings
- Confidential deployment topologies
- Secret material and credentials
- Unapproved patent-sensitive implementation details

## Publication Rule

If uncertain whether material is public-safe, treat it as non-public until owner review confirms publication suitability.
