# Reference Implementation Boundaries

This repository includes a public conceptual reference SDK and demo to illustrate architecture behavior.

## Included in Reference Scope

- Typed conceptual models
- Deterministic policy and approval flow examples
- Capability and connector lifecycle simulation
- Evidence lifecycle simulation
- Incident containment walkthroughs

## Explicitly Excluded

- Production connector credentials
- Real cloud, payment, email, browser, or shell execution paths
- Customer-specific policy logic
- Confidential runtime internals

## Public Claim Boundary

Reference artifacts demonstrate architecture intent. They do not claim production hardening, certification, or universal threat prevention.
