# Interactive Demo

The `interactive-demo/` directory provides a static client-side demonstration of governance lifecycle behavior.

## Included Simulations

1. Governed request simulator
2. Identity and authority validation flow
3. Policy decision and approval flow
4. Capability scope and revocation
5. Connector readiness behavior
6. Runtime state transition view
7. Evidence-chain viewer
8. Continuous verification flow
9. Threat-to-control explorer
10. Incident containment walkthrough
11. Diagram explorer

## Hosting Targets

- Local browser
- GitHub Pages subpath (`/demo/`)
- Hugging Face Static Space mirror

## Guardrails

- No backend
- No secrets
- No external execution
- No analytics or user tracking
